## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | /metrics/landing response | accept | Public endpoint with non-sensitive display data (volume, pace, engagement). Fallback values render if response is malformed. Low-value target. |
| T-04-02 | Tampering | API response values | accept | Display-only metrics. Tampered values (e.g., inflated volume) have no security impact -- only cosmetic. |
| T-04-03 | Information Disclosure | runmidApiClient auth interceptor | mitigate | fetchLandingMetrics catches ALL errors before the 401 interceptor can redirect landing visitors to /login. try/catch wraps the entire axios call. |
| T-04-04 | Denial of Service | Slow/hanging API | mitigate | 5000ms timeout on the axios request. Fallback values render immediately regardless of API state. No loading UI that could be stuck. |
</threat_model>
