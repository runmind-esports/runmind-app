**CircularGauge.tsx** (per D-05, D-06):

Create a `'use client'` component that renders an SVG circular gauge.

Props interface:
```typescript
interface CircularGaugeProps {
  current: number    // currentMana
  max: number        // maxMana
  percentage: number // 0-100
}
```

SVG implementation:
- viewBox="0 0 200 200", circle cx=100, cy=100, r=80
- Background circle: stroke color `var(--border)`, strokeWidth=12, fill="none"
- Progress circle: strokeDasharray and strokeDashoffset to show percentage fill
- Circumference = 2 * Math.PI * 80 = ~502.65
- strokeDashoffset = circumference - (circumference * percentage / 100)
- stroke-linecap="round", transform="rotate(-90 100 100)" so it starts from top
- CSS transition on strokeDashoffset: `transition: stroke-dashoffset 1s ease-out`

Color logic (per D-05):
- percentage > 30 → stroke="#00F048" (green/accent)
- percentage > 10 && <= 30 → stroke="#F59E0B" (yellow)
- percentage <= 10 → stroke="#EF4444" (red)

Center text (per D-06):
- Large text: `{current}` in font-display font-bold text-3xl
- Small text below: `de {max} RunPoints` in text-foreground-muted text-sm
- When current === 0: show "Sem calorias" in red instead of the number
