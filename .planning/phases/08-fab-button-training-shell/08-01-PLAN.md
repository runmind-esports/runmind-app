Create the training feature module directory structure: `src/features/training/hooks/`.

**useDraggable.ts** -- Generic hook for making an element draggable via touch and mouse:
- Accept params: `{ initialPosition: { x: number, y: number }, onPositionChange?: (pos: { x: number, y: number }) => void }`
- Return: `{ position: { x: number, y: number }, isDragging: boolean, ref: React.RefObject<HTMLElement> }`
- On `mousedown`/`touchstart`: record offset between pointer and element top-left, set `isDragging = true`
- On `mousemove`/`touchmove`: calculate new position, clamp to viewport boundaries (element must stay fully visible -- account for element width/height using `ref.current.getBoundingClientRect()`), update position state
- On `mouseup`/`touchend`: set `isDragging = false`, call `onPositionChange` with final position
- Use `useRef` for the element reference, `useState` for position and isDragging
- Attach move/end listeners to `window` (not the element) so dragging works even if pointer leaves the element
- Use `useEffect` cleanup to remove listeners
- Prevent default on touch events to avoid scroll during drag
- Use `useCallback` for event handlers to avoid re-registering listeners

**useFABPosition.ts** -- Hook for persisting FAB position in localStorage:
- localStorage key: `runmind_fab_position`
- Default position: `{ x: window.innerWidth - 76, y: window.innerHeight - 160 }` (bottom-right, above the chat input area). Handle SSR by checking `typeof window !== 'undefined'` and defaulting to `{ x: 0, y: 0 }` until mounted.
- On mount, read from localStorage. If found and valid JSON with x/y numbers, use it. Otherwise use default.
- Expose `savePosition(pos)` that writes to localStorage (debounce not needed since it only fires on drag end).
- Return: `{ position: { x: number, y: number }, savePosition: (pos: { x: number, y: number }) => void }`

**FAB.tsx** -- The floating action button component:
- `'use client'` directive
- Import `useDraggable` and `useFABPosition` from the hooks
- Import `useRouter` from `next/navigation`
- Import `Dumbbell` icon from `lucide-react` (training/workout icon)
- Initialize `useFABPosition()` to get `position` and `savePosition`
- Initialize `useDraggable({ initialPosition: position, onPositionChange: savePosition })`
- On click (only if NOT isDragging -- important to distinguish click from drag): call `router.push('/training')`
- To distinguish click from drag: track a `dragMoved` ref. Set it to `false` on pointerdown, set to `true` on any move during drag. On click handler, only navigate if `dragMoved.current === false`.
- Render a `<button>` element with:
  - `ref` from useDraggable
  - `position: fixed`, `left: position.x`, `top: position.y` as inline styles
  - `z-index: 50` (above chat content, below modals)
  - Size: `w-14 h-14` (56px, good touch target)
  - Shape: `rounded-full`
  - Background: `bg-accent` (#00F048)
  - Opacity: `opacity-70` by default, `opacity-100` on hover and when isDragging. Use Tailwind `hover:opacity-100` plus conditional class for isDragging.
  - Shadow: `shadow-lg` default, `shadow-xl` when dragging
  - Transition: `transition-opacity transition-shadow duration-200` (but NOT transition on position -- that would lag behind drag)
  - Cursor: `cursor-grab` default, `cursor-grabbing` when isDragging
  - Icon: `<Dumbbell className="h-6 w-6 text-background" />` (dark icon on green bg)
  - `touch-action: none` inline style to prevent browser touch behaviors during drag
