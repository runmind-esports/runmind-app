## Layout Contract

### HeroSection Layout

- Full SectionWrapper width with `max-w-7xl` constraint
- Single column on mobile, 2-column grid on `lg:` (content left, mockup right)
- Content column: headline, subtitle, CTA button group stacked with `gap-6`
- CTA group: primary + secondary buttons side by side with `gap-4`
- Mockup column: `AppMockup` component with aspect ratio constraint, hidden on mobile (`hidden lg:block`)
- Vertical centering between columns via `items-center`

```
Mobile (< 1024px):
+----------------------------------+
| Headline (40px Poppins bold)     |
| Subtitle (16px Manrope muted)   |
| [Comece Gratis] [Saiba Mais]    |
+----------------------------------+

Desktop (>= 1024px):
+------------------+---------------+
| Headline         |               |
| Subtitle         |  App Mockup   |
| [CTA] [CTA2]    |  (Placeholder)|
+------------------+---------------+
```

### FeaturesSection Layout

- Section title + subtitle centered, `text-center`, `max-w-2xl mx-auto`
- 3-column grid on `lg:`, single column on mobile, 2-column on `md:`
- Grid classes: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6 lg:gap-8`
- Below feature cards: Strava + Garmin integration badges row, centered, `flex justify-center gap-6 mt-8`

### ProfilesSection Layout

- Section title centered
- 4-column grid on `lg:`, 2-column on `md:`, single column on mobile
- Grid classes: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4 lg:gap-6`
- Each card is a vertical stack: emoji/avatar, name, stat (accent), description

### CTASection Layout

- Centered text alignment, `text-center max-w-2xl mx-auto`
- Heading, subtitle, and single CTA button stacked with `gap-6`
- Optional subtle radial gradient behind CTA for visual emphasis: `bg-gradient-radial from-accent-dim/20 to-transparent`

### FooterSection Layout

- Top row: 2-3 columns on `md:+`, single column on mobile
- Column 1: RunMind logo + tagline
- Column 2: Product navigation links (vertical list)
- Column 3: Account links (vertical list)
- Bottom row: copyright line centered, separated by `border-t border-border pt-8 mt-8`
- Grid classes: `grid grid-cols-1 md:grid-cols-3 gap-8`

## Accessibility

- All CTA links use semantic `<a>` via Next.js `Link` component
- Feature card icons have `aria-hidden="true"` (decorative)
- Section headings follow semantic order: `<h1>` in hero only, `<h2>` for section titles
- Color contrast: accent green `#00F048` on dark background `#14162E` = 8.4:1 ratio (AAA)
- Color contrast: dark text `#14162E` on accent green `#00F048` for CTA buttons = 8.4:1 ratio (AAA)
- Muted text `#8A8FA8` on dark background `#14162E` = 4.6:1 ratio (AA)
- All interactive elements have minimum 44px touch target
- Footer navigation uses `<nav>` landmark with `aria-label`
- Brand images (Strava/Garmin) use descriptive `alt` text
