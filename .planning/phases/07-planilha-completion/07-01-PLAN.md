**2. Create useSpreadsheetDownload hook:**

Create `src/features/onboarding/hooks/useSpreadsheetDownload.ts` following the `useState` + `useCallback` pattern from `useOnboarding.ts`.

Hook manages 4 states: `'idle' | 'loading' | 'success' | 'error'`.

The `download` callback:
- Sets status to `'loading'`, clears error
- Calls `onboardingApi.downloadSpreadsheet()` to get Blob
- Creates blob URL via `URL.createObjectURL(blob)`
- Creates a hidden `<a>` element, sets `href` to blob URL, `download` attribute to `'planilha-runmind.xlsx'` (per D-02)
- Appends to `document.body`, calls `.click()`, removes element
- Calls `URL.revokeObjectURL(url)` to prevent memory leak
- Sets status to `'success'`
- On error: logs via `console.error('Error downloading spreadsheet:', err)`, sets error message string, sets status to `'error'`

Export: `export function useSpreadsheetDownload()` returning `{ status, error, download }`.

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-01 | Spoofing | /planilha route | mitigate | Auth guard via useAuth() + useEffect redirect to /login; backend validates JWT on spreadsheet endpoint |
| T-07-02 | Information Disclosure | Blob download | accept | Spreadsheet contains only the authenticated user's own training data; backend scopes by JWT identity |
| T-07-03 | Denial of Service | Download button | mitigate | Disable button during loading state to prevent repeated API calls |
| T-07-04 | Tampering | Blob URL | accept | Blob URL is ephemeral (revoked immediately after click); no sensitive data exposed in URL |
</threat_model>
