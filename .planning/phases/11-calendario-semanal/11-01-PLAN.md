**hooks/useWeekNavigation.ts** -- Hook for week date range and navigation:

- `'use client'` directive
- State: `weekOffset` (number, default 0 = current week)
- Computed values:
  - `weekStart`: Monday of the target week (offset from today). Use `new Date()`, set to Monday (getDay() === 0 means Sunday, adjust accordingly). Set time to 00:00:00.
  - `weekEnd`: Sunday of the target week, 23:59:59.
  - `weekLabel`: formatted as "DD mon - DD mon" in PT-BR (e.g., "21 abr - 27 abr"). Use Portuguese month abbreviations.
  - `isCurrentWeek`: `weekOffset === 0`
- Actions: `goToPreviousWeek()` decrements offset, `goToNextWeek()` increments (but cap at 0 -- cannot go to future weeks), `goToCurrentWeek()` resets to 0
- Return: `{ weekStart, weekEnd, weekLabel, isCurrentWeek, goToPreviousWeek, goToNextWeek, goToCurrentWeek }`
- Also export a helper: `getDaysOfWeek(weekStart: Date): Date[]` -- returns array of 7 Date objects (Mon-Sun) for the given week

**WeekSelector.tsx** -- Navigation control:
- `'use client'` directive
- Props: `{ weekLabel: string, isCurrentWeek: boolean, onPrev: () => void, onNext: () => void }`
- Render: flex row with `ChevronLeft` button, label text center, `ChevronRight` button
- Styling: `py-3 px-4 flex items-center justify-between`
- Label: `text-sm font-medium text-foreground font-body`
- Buttons: `p-2 rounded-lg hover:bg-background-secondary` with icons (20px)
- Next button: disabled (grayed out, `opacity-30 pointer-events-none`) when `isCurrentWeek`

**DayCard.tsx** -- Single day card:
- `'use client'` directive
- Props: `{ date: Date, activity?: StravaActivity, isToday: boolean }`
- Import `useRouter` from `next/navigation`
- Import `formatDistance`, `formatPace`, `formatDuration` from `../utils/formatters` (or define inline if needed)
- Import icons from lucide: `Footprints` (Run), `Bike` (Ride), `PersonStanding` (Walk) -- map activity type to icon

Day name: Abbreviated PT-BR day name (`['Seg', 'Ter', 'Qua', 'Qui', 'Sex', 'Sab', 'Dom']`). Date number below.

Card styling based on state:
- Has activity: `border-l-4 border-l-green-500 bg-background-secondary`
- Today (no activity): `border-l-4 border-l-accent bg-background-secondary`
- No activity, not today: `border border-border bg-background-secondary opacity-60`
- All cards: `rounded-xl p-3`

With activity content:
- Row 1: Activity type icon (16px) + activity name or type (`text-sm font-medium text-foreground truncate`)
- Row 2: Three inline stats: distance, pace, duration (`text-xs text-foreground-muted`)

Without activity:
- Centered "Descanso" text in `text-xs text-foreground-muted italic`

On tap (when activity exists): `router.push(\`/training/history/${activity.id}\`)` -- navigates to activity detail (Phase 12). For now, this link will 404 until Phase 12 is built, which is acceptable.

**WeekSummary.tsx** -- Weekly aggregated totals:
- `'use client'` directive
- Props: `{ activities: StravaActivity[], isLoading?: boolean }`
- Import formatters
- Calculate from activities array:
  - Total distance: sum of all `activity.distance`, format with `formatDistance`
  - Total runs: `activities.length`
  - Total time: sum of all `activity.moving_time`, format with `formatDuration`
- Render: horizontal row of 3 stats in a `bg-background-secondary rounded-xl p-4 border border-border`
- Each stat: value (`text-lg font-bold text-foreground`) + label (`text-xs text-foreground-muted`)
- Labels: "Distancia", "Corridas", "Tempo"
- When `isLoading`: show shimmer skeleton

**WeekScreen.tsx** -- Composition component:
- `'use client'` directive
- Import `useWeekNavigation`, `getDaysOfWeek` from hook
- Import `useStravaActivities` from `@/features/strava`
- Import `useStrava` from `@/features/strava` for connection check
- Import all week sub-components
- Import `StravaConnectCTA` from `../dashboard/StravaConnectCTA` (reuse from Phase 10 if exists, otherwise import from `@/features/training`)

Logic:
1. `useWeekNavigation()` for date range
2. `useStravaActivities(1, 100)` to fetch activities (fetch a large page, filter client-side by week range)
3. Filter activities: `activities.filter(a => { const d = new Date(a.start_date_local); return d >= weekStart && d <= weekEnd })`
4. `getDaysOfWeek(weekStart)` to get 7 day dates
5. For each day, find matching activity (compare date only, ignore time)
6. Determine `isToday` for each day

Rendering:
- Container: `p-4 space-y-4 max-w-lg mx-auto`
- If Strava not connected: show `StravaConnectCTA`
- Else:
  - `<WeekSelector>` at top
  - `<WeekSummary>` with filtered activities
  - Day cards in a vertical list (`space-y-2`): one `<DayCard>` per day (Mon-Sun)
