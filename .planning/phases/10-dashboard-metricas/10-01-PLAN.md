**utils/formatters.ts** -- Shared formatting utilities for the training feature:

- `formatDistance(meters: number): string` -- Convert meters to km with 1 decimal (e.g., `12345` -> `"12.3 km"`). For values < 1000, show meters (e.g., `"800 m"`).
- `formatPace(avgSpeedMs: number): string` -- Convert m/s to min/km pace string (e.g., `2.78` -> `"6:00 /km"`). Formula: `1000 / avgSpeedMs / 60` for minutes. Format as `M:SS`. Return `"--"` if speed is 0.
- `formatDuration(seconds: number): string` -- Convert seconds to human readable (e.g., `3661` -> `"1h 01min"`). Under 1 hour: `"45min"`. Under 1 minute: `"30s"`.
- `formatDateShort(isoDate: string): string` -- Format ISO date to PT-BR short (e.g., `"23 abr"`). Use month abbreviations in Portuguese: `['jan', 'fev', 'mar', 'abr', 'mai', 'jun', 'jul', 'ago', 'set', 'out', 'nov', 'dez']`.
- `formatTrend(current: number, previous: number): { value: string, isPositive: boolean }` -- Calculate difference and return formatted string (e.g., `{ value: "+12.3 km", isPositive: true }`).
