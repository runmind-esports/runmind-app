**types/workout.types.ts** -- Workout domain types:

```typescript
export interface WorkoutStep {
  id: string
  description: string // e.g., "Corrida leve 10min"
  type: 'warmup' | 'main' | 'cooldown' | 'interval' | 'recovery'
  duration?: number // seconds
  distance?: number // meters
  targetPace?: string // e.g., "5:30-6:00"
  targetHR?: string // e.g., "Z2-Z3"
}

export interface WorkoutPart {
  id: string
  name: string // e.g., "Parte 1 - Aquecimento"
  steps: WorkoutStep[]
}

export interface Workout {
  id: string
  title: string
  date: string // ISO
  description?: string
  parts: WorkoutPart[]
  totalDuration?: number // planned total seconds
  totalDistance?: number // planned total meters
  stravaActivityId?: number // linked Strava activity if completed
}

export interface WorkoutCompletion {
  workoutId: string
  completedAt: string
  distance?: number
  duration?: number
  avgPace?: string
  avgHR?: number
  feeling?: 'easy' | 'moderate' | 'hard' | 'very_hard'
  notes?: string
}
```

NOTE: Since no workout API exists yet (would be a future backend feature), WorkoutScreen will use the Strava activity as the primary data source. The workout "parts" will be mocked/derived from the activity data for now. The types above define the target domain model for when a workout planning API is built.

Each part is a card:
- Header (clickable): `bg-background-secondary rounded-xl border border-border`

  - On click: toggle `expandedPartId`
- Body (visible when expanded): animated max-height transition
  - List of steps in `space-y-2 p-3 pt-0`
  - Each step: flex row with type indicator dot (color-coded: green=warmup, accent=main, blue=cooldown, orange=interval, gray=recovery), description text (`text-sm text-foreground font-body`), and duration/distance badge if present (`text-xs bg-background-tertiary rounded-full px-2 py-0.5 text-foreground-muted`)
- Collapsed state: just the header visible
- All parts collapsed by default; tapping one expands it and collapses others (accordion behavior)

**WorkoutScreen.tsx** -- Main workout detail screen:
- `'use client'` directive
- Props: `{ activityId: number }`
- Import `useActivityDetail` from `@/features/strava`
- Import `useStrava` from `@/features/strava`
- Import `useRouter` from `next/navigation`
- Import `WorkoutParts`, `WorkoutSummary`, `SplitsTable` from relevant paths
- Import icons: `ArrowLeft`, `Bot`, `CheckCircle`

State:
- `isCompleted` (boolean, default false) -- tracks if user marked workout as done
- `feeling` (string | null) -- optional feeling after completion

Logic:
1. `useActivityDetail(activityId)` to fetch Strava data
2. `useStrava()` for connection status
3. Derive workout parts from activity data:
   - If activity has `splits_metric`, create synthetic parts:
     - Part 1 "Aquecimento": first split
     - Part 2 "Principal": middle splits
     - Part 3 "Desaquecimento": last split
   - If no splits, create a single part with the activity name as description
   - Map each split to a WorkoutStep with distance, duration, and pace info

Rendering (scrollable):
- **Header bar** (same pattern as ActivityDetailScreen):
  - Back button -> `router.back()` (or `/training/week`)
  - Activity name + date

- **Workout parts section** (`px-4 pt-4`):
  - `<WorkoutParts parts={derivedParts} />`

- **Completion section** (`px-4 py-4`):
  - If NOT completed:
    - Button: "Marcar como concluido" -- `bg-green-600 hover:bg-green-700 text-white rounded-xl py-3 font-medium w-full flex items-center justify-center gap-2` with `CheckCircle` icon
    - On click: set `isCompleted = true`
  - If completed:
    - **Feeling selector**: "Como foi o treino?" with 4 emoji-free buttons: "Facil", "Moderado", "Intenso", "Muito intenso" -- pill buttons, active one highlighted with `bg-accent text-white`
    - **WorkoutSummary**: populated from Strava activity data (distance, moving_time, average_speed, average_heartrate, calories)
    - **Splits section**: `<SplitsTable>` if splits available

- **"Atualizar a IA" button** (`px-4 pb-8`):
  - Only visible after completion
  - Full-width: `bg-accent hover:bg-accent-hover text-white rounded-xl py-3 font-medium w-full flex items-center justify-center gap-2`
  - `Bot` icon (20px) + "Atualizar a IA"
  - On click: `router.push(\`/chat?context=workout&activityId=${activityId}&feeling=${feeling || ''}&distance=${activity?.distance || ''}\`)`
  - This sends workout context to chat for AI coach feedback
