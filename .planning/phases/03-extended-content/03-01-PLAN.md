   - Import `useRef`, `useState`, `useEffect` from react

   - Export named function `useInView(options: UseInViewOptions = {})`
   - Destructure defaults: `threshold = 0.15`, `once = true`, `rootMargin = '0px 0px -60px 0px'`
   - Create `ref = useRef<HTMLDivElement | null>(null)` and `isInView = useState(false)`
   - useEffect: get `el = ref.current`, return early if null, create IntersectionObserver with callback that sets `isInView(true)` when `entry.isIntersecting` and calls `observer.unobserve(el)` if `once` is true. Observer options: `{ threshold, rootMargin }`. Call `observer.observe(el)`. Cleanup: `observer.disconnect()`.
   - Return type: `[React.RefObject<HTMLDivElement | null>, boolean]`
   - Return `[ref, isInView]`

2. Create `src/features/landing/components/ui/ScrollReveal.tsx`:
   - Add `'use client'` directive
   - Import `useInView` from `../../hooks/useInView`
   - Define `ScrollRevealProps` interface: `children: React.ReactNode`, `className?: string`, `delay?: number`
   - Export named function `ScrollReveal({ children, className, delay = 0 }: ScrollRevealProps)`
   - Call `const [ref, isInView] = useInView({ threshold: 0.15, once: true, rootMargin: '0px 0px -60px 0px' })`
   - Render `<div ref={ref} className={\`scroll-reveal \${className ?? ''}\`} data-inview={isInView || undefined} style={{ transitionDelay: \`\${delay}ms\` }}>{children}</div>`
   - IMPORTANT: use `data-inview={isInView || undefined}` -- attribute absent when false, set to `"true"` string when true

3. Append to `src/app/globals.css` (after the existing typing-dot animations):
   ```css
   /* Scroll reveal animation */
   .scroll-reveal {
     opacity: 0;
     transform: translateY(24px);
     transition: opacity 700ms ease-out, transform 700ms ease-out;
   }

   .scroll-reveal[data-inview="true"] {
     opacity: 1;
     transform: translateY(0);
   }

   @media (prefers-reduced-motion: reduce) {
     .scroll-reveal {
       opacity: 1;
       transform: none;
       transition: none;
     }
   }
   ```
