# Phase 3 — UI Design Contract

> Visual and interaction contract for the Extended Content phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (components.json present, style: default, baseColor: neutral) |
| Preset | default -- cssVariables: false |
| Component library | Radix UI (existing: avatar, button, scroll-area, textarea, theme-toggle) |
| Icon library | Lucide React ^0.312.0 |
| Font (body) | Manrope (400, 700) via Google Fonts import |
| Font (display) | Poppins (400, 700) via Google Fonts import |
| Animation library | CSS keyframes + Intersection Observer API (no Motion dependency yet) |

**Phase 3 scope:** This phase delivers 2 new section components (FlowSection, GapSection), scroll-triggered reveal animations via CSS + Intersection Observer, and hero load animations. It also updates the translation dictionary to replace all `[Phase 3]` placeholders with final copy. No new npm dependencies are added -- animations use CSS `@keyframes` with a lightweight `useInView` custom hook wrapping `IntersectionObserver`.

**Why no Motion library yet:** Research recommended CSS-first animations with Motion only if needed. Phase 3 animations are simple fade/slide-up reveals that CSS handles natively. This avoids 30-50KB bundle bloat on Brazilian mobile 4G connections. Phase 4 counter animations may justify Motion installation; evaluate then.

### ScrollReveal

- Wrapper: `<div>` with conditional class application
- Initial state (CSS): `opacity: 0; transform: translateY(24px)`
- Revealed state (CSS): `opacity: 1; transform: translateY(0)`
- Transition: `transition-all duration-700 ease-out`
- Delay: applied via inline `style={{ transitionDelay: '{delay}ms' }}`
- Respects `prefers-reduced-motion: reduce` -- if enabled, skip animation (render immediately visible)
- Implementation: applies `data-inview="true"` attribute when `useInView` fires, CSS targets `[data-inview="true"]`

```css
/* In component or global CSS */
.scroll-reveal {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity 700ms ease-out, transform 700ms ease-out;
}
.scroll-reveal[data-inview="true"] {
  opacity: 1;
  transform: translateY(0);
}
@media (prefers-reduced-motion: reduce) {
  .scroll-reveal {
    opacity: 1;
    transform: none;
    transition: none;
  }
}
```

### Democratization Callout (inside GapSection, not a separate component)

- Container: `border-l-2 border-accent pl-6 max-w-2xl mx-auto mt-8`
- Text: `text-base font-bold` (foreground color, not muted -- this is a statement, not secondary text)

## Accessibility

- Timeline uses semantic `<ol>` (ordered list) for the 5 steps
- Each timeline step uses `<li>` elements
- Step icons have `aria-hidden="true"` (decorative -- the step number provides semantic meaning via list order)
- ScrollReveal: elements must NOT use `visibility: hidden` or `display: none` as initial state -- `opacity: 0` only, so screen readers can still access content
- Gap stat numbers are plain text (not images), accessible to screen readers
- Democratization callout uses `<blockquote>` or `<aside>` with `role="note"` for semantic meaning
- `prefers-reduced-motion: reduce` disables all animations (elements render immediately visible)
- Section headings continue semantic order: `<h2>` for FlowSection and GapSection titles
