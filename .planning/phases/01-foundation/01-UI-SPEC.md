## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, tag padding |
| md | 16px | Default element spacing, section internal gaps |
| lg | 24px | Card padding (mobile) |
| xl | 32px | Card padding (desktop), layout gaps |
| 2xl | 48px | Section vertical padding (mobile: `py-12`) |
| 3xl | 64px | Section vertical padding (tablet: `py-16`) |
| 3.5xl | 80px | SectionWrapper intermediate vertical padding (`sm:py-20`) |
| 4xl | 96px | Section vertical padding (desktop: `py-24`) |

Exceptions: 80px is added to support the SectionWrapper responsive padding ramp (64px -> 80px -> 96px at mobile -> sm -> lg). This provides a smooth visual transition across breakpoints rather than jumping directly from 64px to 96px.

**SectionWrapper padding contract:**
- Horizontal: `px-4` (16px) at mobile, `sm:px-6` (24px) at 640px, `lg:px-8` (32px) at 1024px
- Vertical: `py-16` (64px) at mobile, `sm:py-20` (80px) at 640px, `lg:py-24` (96px) at 1024px
- Max width: `max-w-7xl` (1280px) centered with `mx-auto`
- Source: ARCHITECTURE.md SectionWrapper pattern

## Typography

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 16px | 400 (regular) | 1.5 | Manrope |
| Label / Small | 13px | 400 (regular) | 1.4 | Manrope |
| Heading (section) | 24px | 700 (bold) | 1.2 | Poppins |
| Display (hero) | 40px | 700 (bold) | 1.1 | Poppins |

**Font weights:** Exactly 2 weights are loaded: 400 (regular) and 700 (bold). Both Manrope and Poppins import only these two weights. Labels differentiate from body text via smaller size (13px) and optional uppercase/letter-spacing treatment, not via font weight.

**Notes:**
- Existing codebase uses `font-display` for headings (Poppins) and `font-sans` for body (Manrope) -- maintain this convention.
- Phase 1 only renders the layout shell with no visible headings or body text beyond placeholder section slots. These values lock the contract for Phase 2.
- Tags and badges in the existing codebase use 10px uppercase with `tracking-[0.14em]`. This is NOT a formal type scale token; it is an inherited codebase convention. It does not count toward the 4-size type scale. If Phase 2+ needs to formalize tag typography, it should be added to the type scale at that time with a maximum of 4 total sizes maintained.

## Layout Contract

### Marketing Layout Shell (`(marketing)/layout.tsx`)

- Does NOT include `QueryProvider` or auth state
- Does NOT include sidebar or app navigation
- Inherits `ThemeProvider` from root layout
- Wraps children with `LanguageProvider`
- Sets appropriate meta tags per locale
- Full-width layout, no max-width constraint at layout level (sections handle their own max-width via SectionWrapper)

### SectionWrapper Component

| Prop | Type | Default | Purpose |
|------|------|---------|---------|
| `id` | `string` | required | Scroll anchor target |
| `children` | `ReactNode` | required | Section content |
| `className` | `string` | `undefined` | Additional classes |
| `dark` | `boolean` | `false` | Alternating dark background (`bg-background-secondary`) |

**Rendered output:**
```html
<section id="{id}" class="px-4 sm:px-6 lg:px-8 py-16 sm:py-20 lg:py-24 max-w-7xl mx-auto {dark && 'bg-background-secondary'} {className}">
  {children}
</section>
```

### Page Orchestrator (`(marketing)/page.tsx`)

- Thin component that imports and composes section components in order
- Wrapped in `LanguageProvider`
- Phase 1 renders placeholder `<div>` elements for each section slot (replaced in Phase 2+)
- Section order: Hero, Features, Profiles, Flow, Numbers, Gap, CTA, Footer

## Interaction Contract

### Language Toggle

- **Trigger:** Click on "PT" / "EN" toggle
- **Behavior:** Instantly swaps all visible text via React context re-render. No page reload, no URL change, no loading state.
- **Persistence:** Cookie `runmind_locale` with `path=/` and `max-age=31536000` (1 year)
- **Default:** `pt-BR` when no cookie is set
- **Visual feedback:** Active language label is bold/highlighted, inactive is muted

### Scroll Anchors

- Each section has a unique `id` attribute via SectionWrapper
- Smooth scroll via CSS `scroll-behavior: smooth` on `html`
- Anchor IDs: `hero`, `features`, `profiles`, `flow`, `numbers`, `gap`, `cta-section`, `footer`
