Create `src/features/onboarding/hooks/useOnboarding.ts` with `'use client'` directive.

Per D-01, use `useState` only (no useReducer, no react-hook-form). The hook manages:

**State:**
- `currentStep: number` — 0 = welcome, 1-10 = questions. Initialize to 0.
- `direction: 'forward' | 'backward'` — for animation direction. Initialize to `'forward'`.
- `answers: Record<string, string | boolean | number | null>` — accumulates answers keyed by question key. Initialize to `{}`.
- `userName: string` — editable name from welcome screen. Initialize from `tokenStorage.getUsername()`. If value looks like an email (contains `@`), split at `@` and use the first part.
- `isSubmitting: boolean` — API call in progress.
- `submitError: string | null` — error message from API failure.

**Navigation functions (all wrapped in `useCallback`):**
- `goNext()` — sets direction to `'forward'`, increments currentStep. On step 10 (last question), calls `submitProfile()` instead.
- `goBack()` — sets direction to `'backward'`, decrements currentStep. Does nothing if step is 0.
- `setAnswer(key: string, value: string | boolean | number | null)` — updates answers[key]. For Q3 (`running` key), when value is `false`, also clear `answers.weeklyKm`.
- `confirmName(name: string)` — sets userName and calls goNext().

**Computed values:**
- `canProceed: boolean` — For welcome step: `userName.trim().length > 0`. For question steps: check the current question's key has a non-null answer in `answers`. For Q3 specifically: if `answers.running === true`, also require `answers.weeklyKm` to be set.
- `isLastQuestion: boolean` — `currentStep === 10`.
- `totalQuestions: number` — always 10.

**Per D-04, create `mapAnswersToRequest(answers, userName): SaveProfileRequest`** inside the hook file (not exported, internal helper):
- `goals: [answers.goal as string]`
- `fitnessLevel`: map number 1-2 to `'beginner'`, 3 to `'intermediate'`, 4-5 to `'advanced'`
- `weeklyKmCapacity`: map string keys — `'upTo5'`=2.5, `'upTo10'`=7.5, `'11to20'`=15.5, `'21to30'`=25.5, `'over30'`=40.0. If `answers.running === false`, use 0.
- `hasRacedBefore: answers.raced as boolean`
- `pace5kSeconds`: map — `'dontKnow'`=0, `'above7'`=450, `'6to7'`=390, `'5to6'`=330, `'below5'`=270
- `preferredDays`: map — `'2days'`=['tuesday','thursday'], `'3days'`=['monday','wednesday','friday'], `'4days'`=['monday','tuesday','thursday','saturday'], `'5plus'`=['monday','tuesday','wednesday','thursday','saturday']
- `otherActivities: { active: answers.otherActivities as boolean }`
- `injuriesHistory: { hasInjury: answers.injury as boolean }`
- `trainingPreference`: map — `'shortIntense'`=`'short_intense'`, `'longModerate'`=`'long_moderate'`, `'any'`=`'any'`
- `includeStrengthTraining: answers.strength as boolean`

**`submitProfile()` async function:**
- Sets `isSubmitting` to true, `submitError` to null.
- Calls `const request = mapAnswersToRequest(answers, userName)`.
- Calls `await onboardingApi.saveProfile(request)`.
- On success: returns the response (caller navigates to `/planilha`).
- On error: sets `submitError` to `'Erro ao salvar perfil. Tente novamente.'`, sets `isSubmitting` to false. Does NOT re-throw.

**Return object:**
```typescript
return {
  currentStep, direction, answers, userName, isSubmitting, submitError,
  canProceed, isLastQuestion, totalQuestions,
  goNext, goBack, setAnswer, confirmName, submitProfile,
}
```

Per D-02: get username via `tokenStorage.getUsername()` imported from `@/shared/lib/apiClient`. If it looks like email, split at `@`.

Code style: single quotes, no semicolons, 2-space indent, trailing commas, named function export `export function useOnboarding()`.
