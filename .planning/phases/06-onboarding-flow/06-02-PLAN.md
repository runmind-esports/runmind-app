**File 1: `src/features/onboarding/components/OnboardingFlow.tsx`**

`'use client'` component. No props (gets everything from `useOnboarding` hook).

Import: `useOnboarding`, `getTranslations`, `WelcomeStep`, `QuestionStep`, `ProgressBar`, `OnboardingNavigation`, `QUESTIONS` from QuestionStep, `useRouter` from next/navigation, `useAuth` from auth hooks.

The component:

1. **Auth check** per D-03: Call `useAuth()` to get `isAuthenticated` and `isLoading`. Use `useEffect` to redirect to `/login` if `!authLoading && !isAuthenticated`. If `authLoading || !isAuthenticated`, return `null`.

2. **Hook integration**: Call `useOnboarding()` to get all state and actions.

3. **Translation**: Call `getTranslations()` once for the `t` object.

4. **Layout** per UI-SPEC layout contract:
```
<div className="bg-white min-h-screen">
  <div className="max-w-lg mx-auto px-6 py-8 lg:px-8 lg:py-12 flex flex-col min-h-screen">
    {/* Header zone */}
    <div className="flex items-center justify-between">
      <span className="font-display font-bold text-lg text-[#14162E]">RunMind</span>
      {currentStep > 0 && (
        <span className="text-[13px] text-[#6B7088]">
          {t.navigation.progress.replace('{n}', String(currentStep))}
        </span>
      )}
    </div>
    {currentStep > 0 && <ProgressBar current={currentStep} total={totalQuestions} />}

    {/* Content zone - animated */}
    <div className="flex-1 flex flex-col justify-center">
      <div
        key={currentStep}
        className={cn(
          'motion-safe:animate-slide-in-right',
          direction === 'backward' && 'motion-safe:animate-slide-in-left'
        )}
      >
        {currentStep === 0 ? (
          <WelcomeStep name={userName} onConfirm={confirmName} />
        ) : (
          <QuestionStep
            questionIndex={currentStep - 1}
            value={answers[QUESTIONS[currentStep - 1].key] ?? null}
            onChange={setAnswer}
            conditionalValue={currentStep === 3 ? (answers.weeklyKm as string | null) : undefined}
            onConditionalChange={currentStep === 3 ? (v) => setAnswer('weeklyKm', v) : undefined}
          />
        )}
      </div>
    </div>

    {/* Footer zone - navigation (only on question steps) */}
    {currentStep > 0 && (
      <OnboardingNavigation
        onBack={goBack}
        onNext={async () => {
          if (isLastQuestion) {
            const result = await submitProfile()
            if (result) router.push('/planilha')
          } else {
            goNext()
          }
        }}
        isFirst={currentStep === 1}
        isLast={isLastQuestion}
        isSubmitting={isSubmitting}
        canProceed={canProceed}
      />
    )}

    {/* Error message */}
    {submitError && (
      <div className="mb-4 p-3 bg-red-50 border border-red-200 rounded-xl text-sm text-red-600 text-center">
        {submitError}
      </div>
    )}
  </div>
</div>
```

Key details:
- Use `key={currentStep}` on the animated div to force React remount (pitfall 2 from RESEARCH.md)
- Use `motion-safe:` prefix for animation classes per D-08 `prefers-reduced-motion`
- `cn()` from `@/lib/utils` for conditional animation class
- On submit success (`submitProfile` returns truthy), navigate to `/planilha` via `router.push`
- Q3 (currentStep === 3) passes conditionalValue/onConditionalChange for the weeklyKm follow-up
